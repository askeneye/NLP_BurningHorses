# Scripts

Place reproducible Python scripts for compiling curated CSVs and generating report plots here.

Scripts should:

1. Read raw or curated inputs using repo-relative paths.
2. Write normalized CSVs to `../curated/` or plot-ready CSVs to `../plots/`.
3. Render figures to `../plots/`.
4. Avoid relying on notebook state.

Notebooks may be used for exploration, but scripts in this folder should be the final source of truth for report figures.
