# Report Plot Styleguide

This guide keeps labels, terminology, and visual encodings consistent across report figures. Avoid markdown tables in these docs because they render poorly in the current viewer.

## Glossary

- CoNLL2003: Use this exact capitalization.
- FewNERD: Use `fine-grained` only when the label level matters.
- k-shot: Use lowercase `k` in prose and axis labels.
- BERT: Supervised BERT token-classification baseline trained directly on the labeled k-shot set.
- Pat+Perm BART (VAL): Single-pattern BART learner with pattern and permutation verbalization. Mark as validation-only placeholder until test decoding is available.
- Orders: Ordering instructions in the input data. Use this term for prompt text that tells the model what entity order to follow.
- Patterns: Prompt templates. Use this instead of naming the source paper when discussing our prompt families.
- Verbalized: Text-form NER data or predictions generated by BART.
- Verbalizer: The conversion convention between structured NER labels and generated text.
- Distillation arrow: Use `→` in method labels when a teacher model or ensemble trains a student model.
- soft_labels: Ensemble vote distributions for distillation. These were explored but shelved, so mark any soft-label result as historical unless revived.
- Strict span F1: Main entity-level metric.
- Token F1: Use only when token-level evaluation is the point.
- Validation score: Not final test performance.
- Test score: Final held-out test performance.
- Pilot: A run useful for design or analysis but not a final report claim.
- Placeholder: Temporary value used for plot design; never present as final evidence.

## Axis Labels

Prefer short labels that fit a two-column academic layout.

- k-shot setting: `k-shot setting`
- Validation strict span F1: `Validation strict span F1`
- Test strict span F1: `Test strict span F1`
- Generic strict span F1: `Strict span F1`
- Strict span F1 on a 0-100 plot: `Strict span F1`
- Token F1: `Token F1`
- Entity mentions: `Entity mentions`
- Entity type: `Entity type`
- Pattern id: `Pattern`
- Ensemble members: `Ensemble members`
- Order candidates: `Order candidates`

Use F1 values on a `0.0` to `1.0` scale unless a specific plot explicitly uses percentages.

## Method Labels

Use these labels in legends and plot data:

- `BERT`
- `Pat+Perm BART (VAL)`
- `Pat+Perm BART ensemble vote`
- `Pat+Perm BART ensemble → BERT`
- `Verbalized ensemble majority`
- `Verbalized BART ens → BERT`
- `soft_labels BART ens → BERT`

If a method is temporary or pilot data, keep the method color stable and encode status with line style, marker style, or alpha.

## Color Palette

Use the same color for a concept across all figures.

- BERT: `#4C78A8`
- Pat+Perm BART (VAL): `#F58518`
- Pat+Perm BART ensemble vote: `#B279A2`
- Pat+Perm BART ensemble → BERT: `#E45756`
- Verbalized ensemble majority: `#72B7B2`
- Verbalized BART ens → BERT: `#9467BD`
- soft_labels BART ens → BERT: `#A0A0A0`
- Entity/data distribution: `#8CD17D`
- Final data annotation: `#222222`
- Placeholder data annotation: `#9D9D9D`

## Status Styling

- `final`: solid line or opaque bar; normal marker.
- `in_progress`: solid line with open marker; include note in caption or plot registry.
- `placeholder`: dashed line or reduced alpha; never use as an unmarked final result.
- `needs_rerun`: dotted line or visibly muted marker; annotate in plot registry.
- `superseded`: do not use in report figures unless a diagnostic comparison needs it.

## Model Family Styling

- Single-model baselines use thin dashed lines.
- Ensemble vote methods use a double-stroked line style.
- Distilled student methods use a thin solid line.
- Markers should stay small so dense report figures do not look crowded.

## Figure Size Defaults

Use matplotlib sizes that fit a two-column report.

- Prefer `Inter` for report plots. Use the Unicode arrow `→` for distillation labels.
- Single-column figure: `figsize=(3.35, 2.2)` inches.
- Wide two-column figure: `figsize=(6.9, 2.6)` inches.
- Use `dpi=300` for PNG export.
- Prefer PDF export for LaTeX/report inclusion when possible.

## File Naming

Use lowercase snake_case file names:

- Curated result CSV: `curated/<topic>_results.csv`
- Plot-ready CSV: `plots/<figure_id>_data.csv`
- PNG figure: `plots/<figure_id>.png`
- PDF figure: `plots/<figure_id>.pdf`

Example figure ids:

- `ablation_k5_test_strict_f1`
- `ablation_kshot_strict_f1`
- `orders_pattern_distillation_subset_size`
- `entity_distribution_conll2003`
